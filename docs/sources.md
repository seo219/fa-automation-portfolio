## 표현 원칙

- 교육 실습 경험과 향후 개선 제안을 구분했습니다.
- 취업·재직 이력, 자격 취득 여부, 팀 내 기여율, 실무 납품 실적을 추정하지 않았습니다.
- 처리 시간 단축, 정확도, 불량률 등 확인되지 않은 수치를 추가하지 않았습니다.
- 코드에 있는 25개 위치와 24회 루프는 구조 설명이며 실측 결과가 아닙니다.
- 전화번호, 개인 이메일, 학번, 장비 주소, 인증 정보와 비공개 Drive 링크는 공개 문서에 포함하지 않았습니다.
- 원본 발표자료·이력서·강의자료를 통째로 업로드하지 않았습니다.

## 검증 범위

문서의 원본 파일 경로와 공개 저장소 접근 여부를 확인했습니다. PLC 래더를 장비에 다운로드하거나 로봇 모션을 실행하지 않았습니다. 원본 코드의 SDK 호환성·현장 설정·실제 동작 성공은 이 정리 작업의 검증 범위에 포함되지 않습니다.

원본 GitHub 링크는 해당 저장소의 main을 가리키므로 이후 내용이 바뀔 수 있습니다.

## AI 로봇 윷놀이 v7 자료 추가

사용자가 제공한 v7 PPTX의 본문과 발표자 노트에서 로봇암 담당, 구현 흐름, 시험 결과를 확인했습니다. 개인 담당은 사용자 확인과 역할 표·노트를 함께 반영했고, 손목 카메라 보정과 통합 시험 수치는 팀 로봇 모듈 결과로 구분했습니다. 결과보고서 HWP와 원시 시험 로그는 상세 대조하지 않았습니다. [프로젝트 문서](ai-yutnori-robot-arm.md)에 근거 슬라이드와 수치의 조건을 기재했습니다.
