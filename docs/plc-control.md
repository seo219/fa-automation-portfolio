# PLC 공정·구동·네트워크 제어

[← 포트폴리오](../README.md)

> 센서 입력으로 공정 순서를 전개하고, 인버터·서보·원격 I/O로 제어 범위를 확장한 실습입니다.

## 01. 자동화설비 순차 제어

**목적:** 메거진 공급 → 공급·가공 → 송출 흐름을 센서 완료 조건에 따라 순서대로 진행합니다.

- 단계 릴레이를 사용해 현재 공정과 다음 공정을 구분했습니다.
- 실린더 위치와 가공부 상태를 다음 단계의 조건으로 연결했습니다.
- 공정 순서와 입력·출력 관계를 래더와 HMI 자료로 정리했습니다.

[순차 제어 래더](https://github.com/seo219/PLC_Practice/blob/main/ladderPDF/자동화설비산업기사공개문제1번_연속동작제외.pdf) · [HMI 화면](https://github.com/seo219/PLC_Practice/blob/main/ladderPDF/자동화설비산업기사공개문제1번HMI-1.png)

원본 자료명에 따라 이 사례의 범위는 **연속 동작을 제외한 순차 제어**입니다.

## 02. 인버터 아날로그 속도 제어

**목적:** 증감 입력을 속도 지령 데이터와 연결하고 아날로그 출력에 필요한 값으로 변환합니다.

- 0.1초 클럭과 X2/X3 입력에 따라 D0 지령값을 ±20씩 변경했습니다.
- FLT·나눗셈·곱셈 연산을 사용해 출력 범위에 맞는 스케일링 흐름을 구성했습니다.
- 입력 조건, 내부 데이터, 출력 지령 사이의 관계를 정리했습니다.

[아날로그 속도 제어 래더](https://github.com/seo219/PLC_Practice/blob/main/ladderPDF/인버터아날로그속도제어.pdf) · [인버터 실습 폴더](https://github.com/seo219/PLC_Practice/tree/main/inverter)

## 03. 서보 위치결정·티칭

**목적:** QD75 위치결정 모듈과 JOG·티칭 명령을 이용해 이동과 위치 데이터 저장을 실습합니다.

- 정·역 JOG와 위치결정 데이터를 다뤘습니다.
- U8\\G1500, G1517, G1518 등 모듈 버퍼 메모리를 활용했습니다.
- ZP.TEACH1과 위치 번호 데이터를 이용한 티칭 흐름을 구성했습니다.

[서보 티칭 래더](https://github.com/seo219/PLC_Practice/blob/main/ladderPDF/서보모터_티칭_블록_위치지정.pdf) · [서보 실습 폴더](https://github.com/seo219/PLC_Practice/tree/main/servo_mortor)

## 04. CC-Link 원격 I/O·인터록

**목적:** 원격 입력과 출력을 래더 조건에 사용하고 상반된 출력의 동시 동작을 제한합니다.

- X104/X105 원격 입력과 Y122/Y123 원격 출력을 사용했습니다.
- 자기유지 조건과 반대 출력 접점을 조합해 상호 인터록을 구성했습니다.
- 통신 주소와 실제 I/O 동작을 연결하는 흐름을 실습했습니다.

[CC-Link 래더](https://github.com/seo219/PLC_Practice/blob/main/ladderPDF/CCLink실습.pdf)

## 직무와의 연결

| 실습 | 연결되는 업무 |
|---|---|
| 센서 기반 단계 전개 | 공정 시퀀스 해석·수정 |
| 지령값 연산과 스케일링 | 구동 장치의 입력·출력 데이터 해석 |
| JOG와 티칭 | 위치결정 데이터 설정 및 동작 확인 |
| 원격 I/O와 인터록 | 설비 간 신호 관계 분석 |

**범위:** 교육 실습 자료를 정리한 문서입니다. 현장 시운전 실적, 정밀도, 생산성 개선 수치는 별도로 주장하지 않습니다.
