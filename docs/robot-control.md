## 5×5 그리드 반복 이송

[25repeat.py 원본](https://github.com/seo219/neuromeka_Py/blob/main/25repeat.py)

**구현 아이디어:** 반복 좌표를 개별 나열하는 대신 행·열 인덱스로 생성합니다.

| 항목 | 원본 값·구조 |
|---|---|
| 격자 | 5×5, 총 25개 위치 |
| 간격 | 40 mm |
| 좌표 계산 | x = CENTER_X + (row − 2) × 40, y = CENTER_Y + (column − 2) × 40 |
| 위치 구조 | 접근점 → 타겟 → 회수점 |
| 접근 높이 | 타겟 Z + 50 mm |
| 이송 루프 | 1→2, 2→3, …, 24→25 · 코드상 24회 |

Pick은 접근 → 하강 → 흡착 ON → 회수, Place는 접근 → 하강 → 흡착 OFF → 회수 순서입니다. 각 이동 사이에는 모션 완료 대기를 둡니다.

**현재 파일 상태:** CENTER_X, CENTER_Y, TARGET_Z, RX, RY, RZ 대입값이 비어 있습니다. 이 파일은 좌표를 채우기 전에는 Python 구문 실행이 불가능하므로, 바로 실행 가능한 데모로 소개하지 않습니다. 위 횟수는 반복문 구조에 따른 설명이며 성공률이나 실측 성능 수치가 아닙니다.

## 그리퍼·팔레타이징

[gripper.py 원본](https://github.com/seo219/neuromeka_Py/blob/main/gripper.py)

포트폴리오 자료에는 2×2×2 적재 좌표를 층·행·열 오프셋으로 생성하고, 접근·파지·회수·이동·해제 동작을 조합한 실습을 정리했습니다.

- 기계식 그리퍼는 열기·닫기 출력을 구분합니다.
- 진공 흡착은 흡착 ON/OFF를 Pick·Place 순서에 연결합니다.
- 공구 방식에 맞춰 파지와 해제 시점을 모션 사이에 배치합니다.

## 배운 점과 확장 방향

좌표계 선택과 접근·회수 위치는 반복 동작을 읽기 쉽게 만드는 핵심 요소였습니다. 다음 단계에서는 파지 확인 입력, 이동 타임아웃, 설정값 검증을 추가해 명령 실행과 실제 작업 완료를 더 명확히 구분할 수 있습니다. 이 항목들은 향후 개선 방향입니다.

이 저장소에서는 실제 로봇을 연결하거나 원본 모션을 실행하지 않았습니다.
